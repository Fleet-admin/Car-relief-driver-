# Car & Driver Relief Services

Premium fleet booking, on-demand chauffeur relief, and dispatch management platform tailored for West Bengal operations.

View your app in AI Studio: https://ai.studio/apps/1ba5bea0-a151-4afb-b7d9-8dff7ad30441

## Features
- **Interactive Route Planning**: Distance and fare estimations via OpenStreetMap / OSRM.
- **Dynamic Fleet & Pricing**: Customizable vehicle tiers and base rate structures.
- **Admin Dispatch Portal**: Live management for bookings, driver allocations, and inquiries.
- **West Bengal Operational Base**: Centralized dispatch hub centered in Kolkata, WB.

## Run Locally

**Prerequisites:** Node.js (v18+)

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start development server:
   ```bash
   npm run dev
   ```
